# 격자 회피·학습 경로 보호 후보 점검 — 2026-10-15

이 기록은 개발 후보의 **회귀를 포함한 검증용 진단**이다. 전면적인 성능 향상이나
도입 성공을 뜻하지 않는다. 기존 한국 모델이 맞게 따라간 한 구간을 새 경로 보호가
거부해 잘못된 Ink 경로로 되돌렸다. 이 후보는 기본 동작으로 채택하지 않았다.
`learned_observation_gate=False`, `learned_route_guard=False`를 유지하고 격자 회피만
기본 적용하는 구성으로 다시 검사했다. 거부된 후보와 채택한 기본 구성을 아래에서
구분한다.

후속 [회피 비용 분리 검사](UNCALIBRATED_AVOIDANCE_CHECK_2026-10-15.md)는
선택된 경로 비용이 없는 모델에 회피 비용 6을 자동 적용하던 동작을 수정한다.
아래 표는 그 수정 전의 역사 기록이며 후속 결과와 합산하지 않는다.

## 비교 범위와 기준선

- 자료: `usgs-ams-korea-contour-ai-weak-v1`의 Validation 크롭 4개. Calibration과
  Holdout 파일은 열지 않았다. 모델 가중치를 변경하거나 재학습하지 않았다.
- [동결 사례 파일](data/korea-contour-visual-cases-v1.json)의 클릭과 기준선을
  모델 출력을 보기 전에 원본 확대 영상에서 에이전트가 확인했다. 같은 연속
  등고선을 표시했고, 숫자 아래의 보이지 않는 연결은 기준선에 포함하지 않았다.
- `kr-10-crop-01-clear-w`는 모호한 왼쪽 구간을 제외한 66픽셀 클릭 간격의
  구간이다. 다른 사례의 클릭 간격은 약 57–84픽셀이다.
- 기준선은 에이전트가 그린 중심선이며 위치 불확실성은 약 1–2픽셀이다.
  사람 승인과 독립 검수·합의는 **0건**이다. 이 표를 공식 정확도나 한국 지도
  일반화 근거로 사용하지 않는다. 같은 Validation 진단을 보며 비용을 조정했으므로
  독립적인 성능 시험도 아니다.

실제 QGIS 3.44.8의 일회용 프로필에서 같은 클릭으로 Ink, USGS 학습 보조,
한국 학습 보조를 각각 실행했다. Smart Recovery는 껐다. `before`는 새 격자 회피,
관측 잉크 제한과 경로 보호를 모두 끈 구성이고, `after`는 세 가지를 모두 켠
**결합 후보**다. 따라서 학습 보조 전후 차이를 격자 검출 하나의 효과로 해석할 수 없다.

## 거부된 결합 후보의 실제 저장 중심선 결과

F1@2px는 저장된 선과 기준선을 촘촘히 표본화한 뒤, 양방향 2픽셀 이내 비율로
계산한다. `1.000`은 이 허용 오차 안에 있다는 뜻이며 원본 선과 완벽하게 일치한다는
뜻은 아니다.

| 사례 | Ink 전 → 후 | USGS 보조 전 → 후 | 한국 보조 전 → 후 |
|---|---:|---:|---:|
| `kr-10-crop-04-clear-w` | 1.000 → 1.000 | 0.072 → 1.000 | 0.192 → 1.000 |
| `kr-10-crop-01-clear-w` | 0.052 → 0.052 | 0.720 → **0.052** | 1.000 → **0.052** |
| `kr-09-crop-08-curving` | 1.000 → 1.000 | 0.957 → 1.000 | 1.000 → 1.000 |
| `kr-09-crop-05-grid-crossing` | 1.000 → 1.000 | 0.040 → 1.000 | 0.103 → 1.000 |

후보의 세 방식은 모두 같은 3개 사례에서 기준선을 따르고, `kr-10-crop-01`에서는
같은 잘못된 경로를 따른다. 기존 Ink는 앞의 3개 사례를 이미 맞게 따라갔다.
따라서 이 실제 사례만으로 Ink 자체의 정확도가 개선됐다고 말할 수 없다.

경로 보호는 학습 후보가 관측 잉크를 버리는 것을 막지만, Ink가 잘못된 등고선을
고른 경우까지 보존한다. `kr-10-crop-01`의 한국 보조는 이전에는 맞았으나 후보에서는
틀렸다. 저장 선에서 기준선까지 거리의 p95도 **0.995 → 9.040픽셀**로 악화됐다.
반대로 `kr-09-crop-05`의 한국 보조 p95는 16.200 → 1.146픽셀로 줄었다.
좋아진 사례만으로 이 회귀를 상쇄해 도입 합격으로 처리하지 않는다. 코어에서 각
설정을 분리한 추가 진단에서도 경로 보호 단독으로 이 실패를 재현했다. 관측 잉크
제한만 적용해도 이미 잘못된 일부 경로가 조금 더 나빠졌으므로 두 설정을 모두 기본
OFF로 남긴다. 이 코어 진단은 저장·평활화까지 포함한 QGIS 결과와 수치가 다를 수 있다.

## 격자 회피만 적용한 기본 구성 재검사

새 기본 구성은 학습 경로 보호와 관측 잉크 제한을 적용하지 않는다. 같은 동결
사례에서 같은 클릭으로 QGIS 저장 비교 24회를 다시 완료했다. 격자 회피만 켜면
네 사례 모두 각 방법의 기존 F1@2px와 p95가 유지된다.

| 사례 | Ink 전 → 후 | USGS 보조 전 → 후 | 한국 보조 전 → 후 |
|---|---:|---:|---:|
| `kr-10-crop-04-clear-w` | 1.000 → 1.000 | 0.072 → 0.072 | 0.192 → 0.192 |
| `kr-10-crop-01-clear-w` | 0.052 → 0.052 | 0.720 → 0.720 | **1.000 → 1.000** |
| `kr-09-crop-08-curving` | 1.000 → 1.000 | 0.957 → 0.957 | 1.000 → 1.000 |
| `kr-09-crop-05-grid-crossing` | 1.000 → 1.000 | 0.040 → 0.040 | 0.103 → 0.103 |

잘되던 한국 보조 사례가 다시 유지되지만, 두 개의 기존 실패도 그대로다. 이 결과는
실제 지도에서 격자 회피의 정확도 향상을 입증하지 않는다. 격자를 따라가던 합성
사례에서는 방향 비용이 등고선 경로를 선택하게 하고, 실제 횡단 사례에서는 기존
Ink 경로를 막지 않는 것을 확인했다. 같은 등고선 유지는 여전히 미해결이다.

## 구현 후보와 한계

- 원본 Byte 회색조/RGB(A)의 저채도 어두운 선에서 수평·수직의 긴 선군을 찾는다.
  각 방향에 분리된 선이 적어도 2개 있어야 하며, 약 ±1.8도 범위의 작은 기울기만
  다룬다. 단독 십자나 짧은 직선은 격자로 확정하지 않는다.
- Live-Wire에서는 격자를 **따라가는 방향**에 유한한 추가 비용을 준다. 가로지르는
  이동은 약하게 벌점화하며, 픽셀을 삭제하거나 통과 불가능한 벽으로 만들지 않는다.
  Smart Recovery에는 같은 격자의 약한 유한 비용을 전달한다.
- 진단용 옵션으로 학습 지지 점수를 관측 중심선 주변과 원본 잉크 대비가 있는
  곳으로 제한하거나, 기존 Ink 경로와 학습 후보를 비교할 수 있다. 위 회귀 때문에
  둘 다 기본 OFF다. 같은 등고선의 정체성을 보장하는 기능도 아니다.
  경로 보호는 hover마다 전체 캐시를 비교해 지연도 늘릴 수 있다. 기본 구성에서는
  이 비교와 추가 Ink 트리를 실행하지 않는다.
- 진한 파랑·갈색, 큰 회전, 끊긴 격자, 지도 가장자리와 격자처럼 긴 지형선은
  검출 실패·오검출 가능성이 있다. 검출은 현재 캐시 문맥에 의존하므로 화면 이동 후
  같은 픽셀의 격자 판정이 항상 같다고 보장하지 않는다.
- 비용 밴드는 좁게 유지한다. 넓은 밴드는 실제 교차 등고선을 해쳤으며, 반대로
  합성 7·9픽셀 폭의 굵은 격자는 가장자리를 따라가 회피하지 못했다.
- 검출 실패·취소와 지원하지 않는 래스터는 기존 Ink 흐름을 유지한다. 학습 모델은
  여전히 선택 기능이며, 성능·메모리·hover 지연의 목표 달성은 이 진단으로 검증하지 않았다.

## 숫자 `1176` 아래의 연결

기존 `Label-gap bridge`는 사용자가 대응하는 양끝을 지정하면 끝점 방향을 이용해
제한된 Hermite 곡선을 미리 보여주는 기능이다. 숨겨진 등고선의 정답을 복원하는
모델은 아니다.

`kr-10-crop-08`의 `1176` 주변을 원본 확대 영상으로 점검했다. 여러 이웃 등고선이
숫자에 가려져 끝점 대응을 확정할 수 없었다. 시험한 3쌍 모두 양끝 방향을 충분히
읽지 못해 기존 보호 조건에서 거부됐다. 이 사례의 자연스러운 연결을 성공했다고
기록하지 않으며, 임의로 만든 연결을 정답이나 새 학습 자료에 넣지 않았다.

## 재현과 산출물 결속

아래 경로는 사용자의 로컬 자료 위치로 대체한다. 원본 크롭, 모델, QGIS 결과 JSON과
확대 비교 이미지는 저장소에 추가하지 않는다.

```bash
python scripts/qgis_grid_comparison.py \
  --zip /path/to/current-development.zip \
  --fixtures learning/data/korea-contour-visual-cases-v1.json \
  --dataset /path/to/korea/dataset \
  --old-model /path/to/ai-weak-contour-guide-v1 \
  --new-model /path/to/ai-weak-contour-guide-korea-v1 \
  --learned-dependencies /path/to/qgis-learned-deps \
  --output /path/to/grid-evaluation/default/result.json
```

`--after-avoidance 6 --observation-gate --route-guard`를 추가하고
별도 출력 위치를 사용한다. 이 진단은 제품 기본 설정과 구분해야 한다.
