# 미보정 학습 회피 비용 분리 — 2026-10-15

> 후속 원본 감사에서 기존 `kr-10-crop-01-clear-w`가 이웃 등고선으로 시작하는
> 잘못된 참조임을 확인했다. 그 행과 이를 포함한 "3→5건" 합계는 철회한다. 원본
> 결과와 참조는 수정하지 않고 보존하며, 그 행을 모델 정답·비퇴행 근거로 사용하지
> 않는다. 별도 동결한 올바른 클릭과 나머지 6건의 현재 비교는
> [U자 검사 기록](U_CONTOUR_CHECK_2026-10-15.md)에 있다.

경로 비용 선택 기록이 없는 모델의 문자·도로 회피 점수에 기본 비용 6을 자동
적용하던 동작을 제거했다. 이 모델은 등고선 지지 점수만 사용한다. 실제 등고선을
문자로 오판한 점수가 누적되어 옆 등고선이나 백지를 가로지르는 경로가 선택되는
문제를 줄이기 위한 변경이다. 모델을 재학습하거나 ONNX 출력을 바꾸지 않았다.

## 동작과 범위

- 번들에 유효한 `selected_guidance`가 있으면 기존 지원·회피 가중치를 그대로
  사용한다. 형식에는 Calibration·Holdout 보고서 해시와 합격 표식이 필요하다.
  이 형식 검증 자체가 외부 보고서의 내용이나 사람 승인을 독립 검증하지는 않는다.
- 설정이 없거나 `null`이면 지원 0.8, 학습 회피 0을 사용한다. 상태와 툴팁에
  `등고선 지지만 사용 · 문자 회피 설정 없음`을 한국어·영어로 표시한다.
- UI, 직접 생성한 map tool, Live-Wire와 Recovery에 같은 정책을 전달한다.
  사용자의 수동 회피 영역과 선 색상 힌트는 유지한다. 명시적인 진단 비용 6도
  사용할 수 있다. 학습 기능 자체는 계속 기본 OFF다.
- 기존 Ink 경로로 되돌리는 보호와 관측 잉크 근처로 지지를 제한하는 후보는
  계속 OFF다. 단일 기존 경로를 정답으로 삼지 않는다.

## 원인 검사

실제 한국 모델의 `kr-10-crop-04` 원시 코어 그래프에서 올바른 경로의 비회피 비용은
150.56, 추가 학습 회피 비용은 15.56이었다. 틀린 경로는 각각 151.68과 9.97로,
회피 비용이 경로 순서를 뒤집었다. `kr-09-crop-05`에서도 실제 등고선에 회피 비용이
더 크게 누적됐다. 이 수치는 QGIS 평활화 이전의 진단이며 아래 저장 선 점수와 다르다.

방향 벌점 증가, 관측 접선의 백지 확장, 잉크 대비 비용, 두 학습 헤드의 상충 점수
정규화를 별도로 시험했다. 일부 사례를 고치면 다른 성공 사례가 나빠져 기본값으로
채택하지 않았다. 네 사례에 맞춘 계수로 같은 등고선 유지가 해결됐다고 주장하지 않는다.

## 원본 검수와 실제 QGIS 비교

[기존 4건](data/korea-contour-visual-cases-v1.json)에
[추가 3건](data/korea-contour-visual-cases-v2.json)을 더했다. 추가 사례는 모델·추적
결과를 보기 전에 원본을 8배로 확대해 전 경로와 양끝을 에이전트가 확인하고 동결했다.
참조는 보이는 연속 등고선만 그렸으며 숫자 아래의 가상 연결은 포함하지 않는다.
원본 검수 패널·양끝 확대·동결 기록은 로컬 결과와 함께 보존했다.

일곱 건 모두 `usgs-ams-korea-contour-ai-weak-v1`의 Validation이다. Calibration과
Holdout 이미지·주석은 열지 않았다. 기존 4건은 개발 중 반복 사용됐으며, 추가 3건도
같은 Validation 도엽에서 선택했으므로 독립 평가가 아니다. 사람 승인과 독립 검수·합의는
0건이다. 참조 위치 불확실성은 약 1–2픽셀이며 공식 정확도·한국 지도 일반화 근거가 아니다.

QGIS 3.44.8의 일회용 프로필에서 같은 두 클릭으로 최종 저장 선을 비교했다.
격자 회피는 전후 모두 ON, Recovery는 OFF이며 이전 경로 보호도 전후 모두 OFF다.
전은 지원 0.8·학습 회피 6, 후는 지원 0.8·학습 회피 0이다. 아래는 F1@2px다.

## 남은 실패와 절충

미보정 회피를 빼면 모델이 문자·도로를 잘 구분하던 이점도 잃을 수 있다. 기존 합성
유색 선과 검정 지름길 실험에서도 회피가 없으면 잘못된 검정 경로를 선택할 수 있었다.
회피를 적용하는 계약 시험은 별도의 **시험용 선택 설정**을 명시하며, 그 가짜 보고서
해시를 실제 성능 검증으로 사용하지 않는다.

깊은 U자를 따라 멀리 돌아야 하는 실제 구간에서 짧은 인접 선을 고르는 문제는 남았다.
모델 지원 점수도 백지를 싸게 만들 수 있으며, 픽셀별 두 점수만으로 선의 정체성을
확정할 수 없다. 추가 재학습 전에는 사람 검수 주석과 선 연결 관계를 평가할 자료가
필요하다. 숫자로 끊긴 구간의 자동 연결을 이번 변경의 성과로 포함하지 않는다.

관측 skeleton 연결만 쓰는 외부 진단도 수행했다. `deep-u`는 그 경로로 F1=1.000이
가능했지만, 기존 성공 `kr10-01`은 0.056으로 퇴행했다. 같은 8연결 성분에 두 끝점이
있어도 이웃 등고선으로 우회한 거대 성분일 수 있으므로 자동 교체하지 않았다.

## 재현과 산출물

`scripts/qgis_grid_comparison.py`의 기본 후 구성은 모델의 비용 정책을 따른다.
이전의 미보정 비용 6을 명시적으로 비교하려면 `--after-avoidance 6`을 사용한다.
이 역사 기록을 재현할 때는 `--no-observed-connections --allow-withdrawn-cases`를
추가하고 결과를 정확도 근거로 쓰지 않는다.

```bash
python scripts/qgis_grid_comparison.py \
  --zip /path/to/current-development.zip \
  --fixtures learning/data/korea-contour-visual-cases-v1.json \
  --dataset /path/to/korea/dataset \
  --old-model /path/to/ai-weak-contour-guide-v1 \
  --new-model /path/to/ai-weak-contour-guide-korea-v1 \
  --learned-dependencies /path/to/qgis-learned-deps \
  --grid-in-both --output /path/to/continuity-evaluation/existing/result.json
```

추가 3건은 `--fixtures`를 `korea-contour-visual-cases-v2.json`으로 바꾸고 별도 출력한다.
