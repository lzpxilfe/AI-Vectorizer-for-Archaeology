# 깊은 U자 관측 연결과 원본 재감사 — 2026-10-15

깊은 U자 두 구간에서 다른 등고선으로 가로질러 가던 경로를 수정했다. 원본 Ink v2
중심선이 두 클릭 사이에 이어져 있으면, 같은 탐색 창의 연결 경로를 먼저 사용한다.
학습 모델·정답 참조로 새 연결을 만들거나 기존 Ink 결과를 정답으로 삼지 않는다.
실제 교차·분기의 정체성을 보장하는 기능은 아니다.

## 잘못된 비교 사례 철회

이전 `kr-10-crop-01-clear-w`의 시작 `(x223,y45)`는 목표 곡선의 시작이 아니라
이웃한 거의 수직인 등고선 쪽이다. 첫 참조 구간은 종이를 약 5픽셀 가로질러
`x228` 부근 목표 등고선으로 옮겨갔다. 해당 수직선은 지도 격자선으로 판정하지 않는다.
그 행의 모델 F1=1.000은 올바른 같은 등고선 추적을 뜻하지 않았다.

별도 에이전트가 예측을 열지 않고 기존 7건의 원본 전체 경로 8배·양끝 10배 영상을
다시 감사했다. 그 결과 6건 유효, 위 1건 무효였다. 기존 참조와 결과 바이트는
수정하지 않고 보존하되 그 행, 포함 합계, 그 행에서 도출한 정답 거부 해석을 철회한다.
특히 이전 "3→5건" 합계와 그 사례를 비퇴행 제약으로 사용하던 판단은 인용하지 않는다.

시작을 실제 등고선 `(x228,y45)`로 옮기고 끝 `(x289,y45)`는 유지한 별도 사례를
원본에서 수동으로 다시 그려 **예측 확인 전에 동결**했다. 기존 6개 참조 좌표는 그대로다.
현재 [v3 사례](data/korea-contour-visual-cases-v3.json)는 이 7건을 담고,
[감사 기록](data/korea-contour-case-audit-v1.json)은 철회 이유를 담는다.
비교 도구는 철회된 ID를 기본 거부하며 과거 재현만 명시적으로 허용한다.

이것은 에이전트 원본 시각 검토이며 인간 승인이나 독립적인 성능 평가가 아니다.
위치 불확실성은 약 1–2픽셀이다. 모두 같은 Validation 도엽에서 반복 개발한 사례이며
Calibration·Holdout은 열지 않았다. 데이터·모델 가중치·학습 분할은 변경하지 않았다.

## 경로 선택 변경

- 기존 픽셀 그래프를 만든 작업 스레드에서 원본 `LineEvidence.centerline` 노드와
  그 사이의 8이웃 간선만 압축한다. 팽창·closing·백지 링크를 추가하지 않는다.
  기존 방향·격자 비용을 간선에서 그대로 읽는다.
- 클릭 주위 2픽셀 안의 가장 가까운 관측점만 연결한다. 가까운 옆 선으로 움직여
  더 싼 경로를 사지 않도록 최소 거리에서 0.25픽셀보다 먼 후보는 제외한다.
- 이어진 관측 경로는 별도로 길이를 제한한다. 직선 거리의 최대 6배, 창 크기의
  최대 2배이며, 길이 제한을 넘으면 기존 픽셀 경로를 사용한다. 픽셀 경로의 기존
  우회 제한 3배는 바꾸지 않는다.
- 관측 끊김·클릭 주변 관측점 없음·과도한 우회·준비 실패는 기존 픽셀 경로를
  유지한다. 실제 수동/색상/학습 회피 비용이나 기존 색상 공백 연결이 있으면 그
  비용 방식도 유지한다. 0%에서는 추가 트리를 만들지 않는다.
- 준비 결과는 불변 배열이며 기존 작업의 세대·캐시 식별자와 함께 게시한다.
  hover에서는 작은 끝점 탐색과 제한된 predecessor 조회만 하고 강도 혼합은 한 번만 한다.
- 끊어진 검정 선의 양쪽 조각이 기호·다른 선을 통해 간접 연결된 회귀 사례도
  확인했다. 기존 픽셀 경로가 분기 없는 두 끝점을 같은 방향으로 이미 잇고 있다면
  그 경로를 보존한다. 끝점의 관측 방향·거리·직선 근접성을 검사할 뿐 새로운
  공백 경로나 숫자 아래의 정답을 생성하지 않는다. 색상 공백 연결도 유지한다.
- 과도하게 긴 관측 연결은 복원하면서 길이를 누적해 한계를 넘는 즉시 중단한다.
  공백 보존용 기존 경로 검사도 창 크기에 비례해 제한한다. 거부될 긴 뱀 모양 경로를
  hover 때 끝까지 순회하던 성능 회귀를 막는다.
- 기본 6픽셀 스냅이 시작점을 고르는 좁은 U자에서도 유효한 관측 경로를 버리지
  않는다. 실제 트리 생성으로 0%·50%·100%와 정확한 끝점을 확인했다.

관측선이 문자·기호·이웃 선과 실제로 붙었으면 같은 연결 성분이 같은 등고선을
뜻하지 않는다. 잘못된 분기를 고를 수 있으며, 보이지 않는 숫자 아래 연결을 이번
성과로 포함하지 않는다. 초록 미리보기 검수와 추가 앵커가 계속 필요하다.

## QGIS 최종 저장 선 비교

QGIS 3.44.8의 일회용 프로필에서 동일 클릭·원본 문맥으로 Ink, USGS 지지 보조,
한국 지지 보조를 비교했다. 전후 모두 격자 회피 ON, 지원 0.8·학습 회피 0,
Recovery OFF다. 전은 관측 연결 우선 OFF, 후는 ON이다. 이전의 관측 지지 제한과
Ink 경로 보호는 양쪽 모두 OFF다. 참조 좌표는 경로 계산에 사용하지 않는다.

|---|---:|---:|---:|
| kr10-04 clear-w | 1.000→1.000 | 1.000→1.000 | 0.433→0.433 |
| kr09-08 curving | 1.000→1.000 | 1.000→1.000 | 0.496→0.496 |
| kr09-05 grid-crossing | 1.000→1.000 | 1.000→1.000 | 1.146→1.146 |
| kr10-02 deep-u | 0.132→**1.000** | 0.402→**1.000** | 7.993→**0.966** |
| kr10-06 dense-s | 1.000→1.000 | 1.000→1.000 | 1.147→1.147 |
| kr09-02 index-u | 0.528→**0.991** | 0.483→**0.991** | 6.701→**1.982** |
| kr10-01 corrected-raw-v1 | 1.000→1.000 | 1.000→1.000 | 0.858→0.855 |

유효한 같은 7건에서 기존 성공 5건의 F1을 유지했고 p95도 악화되지 않았다. 두 U자 모두 전체 미리보기와
저장 선을 확대 확인해 같은 등고선을 유지한다. `index-u`의 작은 잔여 차이는 굵은 선의
오른쪽 아래 굽이에서 참조 중심 위치와 어긋난 것이며, 참조에 맞춰 곡선을 조절하지 않았다.
F1=1.000은 2픽셀 허용 오차 안이라는 뜻이며 정확한 원본 복제나 다른 지도 일반화를 뜻하지 않는다.

F1은 선을 0.5픽셀 이하 간격으로 조밀하게 만든 뒤 양방향 근접률로 계산한다.
p95는 저장 선에서 참조로 향하는 거리의 95백분위다. GUI 클릭은 정수 화면 좌표로
입력하므로 재실행 때 끝점에 1픽셀 미만의 차이가 생길 수 있다. 위 표는 최종 ZIP의
한 실행에서 동일 클릭으로 비교한 값이며, 반복 실행의 좌표가 완전히 같다는 뜻은 아니다.

USGS 보조도 같은 관측 경로를 사용해 후 결과가 Ink·한국 보조와 같다. 이 결과는
새 학습 모델의 성능 향상을 입증하지 않는다. 수정한 경로 알고리즘의 개발 진단이다.

## 재현

```bash
python scripts/qgis_grid_comparison.py \
  --zip /path/to/current-development.zip \
  --fixtures learning/data/korea-contour-visual-cases-v3.json \
  --dataset /path/to/korea/dataset \
  --old-model /path/to/ai-weak-contour-guide-v1 \
  --new-model /path/to/ai-weak-contour-guide-korea-v1 \
  --learned-dependencies /path/to/qgis-learned-deps \
  --grid-in-both --before-avoidance 0 \
  --output /path/to/u-continuity/deliverable/result.json
```

출력은 `result.json`, `scores.json`과 원본/참조/세 방법 전후 확대 비교 이미지다.
데이터와 두 모델의 해시는 [이전 비용 기록](UNCALIBRATED_AVOIDANCE_CHECK_2026-10-15.md)과 같다.
원본·모델·전체 결과·이미지는 git 밖에 보존한다. 최종 ZIP은
`ai_vectorizer-unreleased-u-contours.zip`이며 공개 릴리스·버전 변경은 없다.
