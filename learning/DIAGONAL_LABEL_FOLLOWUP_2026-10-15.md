## 변경한 동작

문자 검출 영역의 2px 여유 부분을 실제 문자의 볼록 영역과 분리했다. 숫자 근처의
연속선이 그 여유 영역에 들어와도 관측 그래프에서 지우지 않는다. 후보는 여전히
원본 중심선의 실제 차수 1 끝점끼리만 만들며, 잘라 만든 끝점은 순서·장벽 검사에만
남긴다. 숫자 전체의 기울기가 곧 등고선 방향은 아니므로, 한 글자만 가로지르는 짧은
공백도 양쪽 실제 끝점과 부호 있는 방향이 맞으면 검토한다.

긴 관측 문맥 중간의 급한 굽이가 기존 8–12px fit을 깨뜨리는 경우, 연결되지 않은
짧은 조각으로 대체하지 않는다. 동일한 8px 이상의 원본 실선 문맥을 유지하면서
가까운 4px·6px 접선의 잔차·방향 일치가 모두 안정적일 때만 가까운 접선을 보완한다.
기존 두 캐시에서 성공했던 2,045개 fit은 그대로였고, 짧은 안쪽 끝점은 계속 거부됐다.

600 U자의 이전 Ink 경로는 보이는 양쪽 선을 이미 잘 따르는 경우에도 새 곡선으로
교체돼 점수가 낮아졌다. `occlusion_route_guard.py`는 원본 숫자 마스크·실제 끝점·
현재 두 경로만 읽어, 기존 경로가 같은 끝점을 순서대로 지나고 마스크 밖의 가시선을
양방향 1.25px 안에서 유지하는지 검사한다. 루프·과도한 우회·끝점 생략·다른 선과
복수 숫자 통과는 거부한다. 통과하면 원래 Ink 경로와 평활화를 보존한다. 제품은
평가 참조나 unknown 영역을 읽지 않는다.

표시 충돌 검사도 수정했다. 추정 곡선 주변의 실선을 자동으로 같은 선으로 취급하던
허용 영역을 제거하고, 실제 관측 prefix/suffix와 두 끝점만 허용 영역을 만든다.
전체 곡선이 옆 선과 1.16px 떨어져 있어도 보조율 적용 후 겹치면 거부한다.

## 입력을 고정한 실제 QGIS 비교

기존 비교의 화면 정수 좌표 반올림은 같은 source prompt를 약간 다른 native 위치로
보낼 수 있었다. 이제 native 픽셀 하나를 화면 정수 2px에 맞춰 실제 일반 클릭을
보내고, QGIS가 읽은 지도 좌표의 round-trip을 확인한다. 경로 주입·단축키·직접 저장
주입은 없다. 짧은 클릭 간격도 제품의 spot-height gesture와 혼동되지 않는다.

`--baseline-zip`은 이전/현재 ZIP을 서로 다른 profile에서 실행한다. 자동 문자 연결,
격자 회피와 모델 가중치는 양쪽 모두 같고, 실제 입력 좌표가 다르면 비교를 거부한다.
같은 이전 ZIP을 두 번 실행한 600 U자 비교에서도 세 방법의 저장 좌표가 완전히 같았다.
이렇게 고정한 기준 F1은 이전 보고서의 0.958과 조금 다른 0.957이다.

가려진 영역을 제외한 가시선만 측정한 결과다.

| 대각선 바깥 600 | USGS guide | 0.279 → 1.000 | 10.109 → 0.471px |

대각선은 보이는 굽이를 보존한 뒤 실제 공백만 연결하며 세 방법 모두 일반 클릭으로
저장·Undo했다. 600 U자의 Ink는 기존의 좋은 경로를 유지한다. 두 guide의 U자 지표는
아직 1.000이 아니며, 이번 수정이 그 잔여 오차까지 없앴다고 주장하지 않는다.

700은 세 방법 모두 저장 좌표와 가시 F1 1.000을 유지했다. 기존 7건 × 세 방법도
21개 저장 좌표 쌍이 완전히 같았다. 이전 잘못된 대각선 쌍과 600 옆 선 쌍에는 새
자동 곡선이 없고 기존 fallback 좌표가 같았다. 이 음성 쌍에는 같은 등고선 정확도
점수를 부여하지 않는다. 기존 Ink fallback 자체가 모든 잘못된 클릭을 막는 것은 아니다.

Calibration·Holdout과 학습 자료를 열거나 재학습하지 않았다. 이 작은 개발 진단은
숨은 원형·일반 지도 정확도·독립 성능 검증을 확정하지 않는다.

## 재현과 검증

최종 source/package 결속, 시험과 결과 해시는
[기계 판독 기록](data/diagonal-label-followup-2026-10-15.json)에 기록한다.
일반 pytest 1,023 통과·154 skip·171 subtest 통과 후, 최종 ZIP의 Python 44개가
소스 및 실제 비교에 사용한 코드와 같음을 확인했다. ZIP을 푼 실제 QGIS import와
162개 시험은 skip 없이 통과했고, clean-profile 9개 흐름은 경고 0·종료 0이었다.
두 버전의 숫자 5건·기존 7건 비교 프로세스도 모두 종료 0이었으며 profile을 제거했다.
공개 AMS 원본에서 추출한 64×64 native topology 회귀 fixture도 추가했다. 실제
8이웃 그래프의 회전·반사 8조건에서 바깥 선의 굽이와 실제 끝점 연결을 유지하고
옆 선 목표를 거부했다. 같은 조건의 이전 `f1bc3aa` 코드는 8조건 모두 연결하지 못했다.
이 fixture는 출처·공개 도메인 권리·crop 위치·원본 해시를 기록하며 숨은 곡선 정답은 없다.
최종 ZIP SHA-256은 `b7d96e84552f4e6837ac62b91e98ea36a44864b3bc80a464569c158bb155db9d`다.
원본 감사·실제 좌표·PNG·NPZ·일회용 profile 실행 로그는 작업 artifact의
`work/diagonal-followup/`에 보존한다. 공식 artifact와 별도로 Unreleased ZIP을 만든다.

```bash
python scripts/qgis_grid_comparison.py \
  --zip /path/to/ai_vectorizer-unreleased-diagonal600.zip \
  --baseline-zip /path/to/ai_vectorizer-unreleased-auto-labels.zip \
  --fixtures learning/data/korea-label-gap-visual-cases-v4.json \
  --dataset /path/to/korea/dataset \
  --old-model /path/to/usgs-model --new-model /path/to/korea-model \
  --learned-dependencies /path/to/qgis-learned-deps \
  --grid-in-both --before-avoidance 0 --compare-occluded-labels \
  --output /path/to/comparison/result.json
```

7건 보존 비교는 fixtures를 `korea-contour-visual-cases-v3.json`으로 바꾼다.
