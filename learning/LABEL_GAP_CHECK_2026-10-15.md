# 라벨 공백 연결 개발 진단 — 2026-10-15

숫자 아래에 숨은 선의 정답을 복원하는 모델을 학습한 결과가 아니다. 짧고 단순한
공백의 제한된 자동 후보와, 사용자가 양끝을 지정하는 `G` 곡선 미리보기를 강화했다.
데이터·모델 가중치·학습 분할은 변경하지 않았으며 모델은 계속 기본 OFF다.

## 두 경로의 범위

자동 후보는 원본 중심선의 실제 끝점과 충분한 단방향 문맥을 요구한다. 끝점 상대가
서로 유일하고 다른 연결 성분에 있으며 방향·곡률 문맥이 맞아야 한다. 원본 연결을
먼저 사용하고, 가상 소스로 시작하는 별도 트리는 경로당 추론 곡선을 하나만 허용한다.
관측 중심선을 팽창하거나 글자 획을 선 지지로 칠하지 않는다. 회피 힌트·색상 공백
연결·0%는 기존 동작을 유지한다. 과도한 탐색은 기존 픽셀 경로로 돌아간다.

자동 탐색은 공백 4–96px, 문맥 12–24px, 원시 끝점 4096개·유효 끝점 256개·후보
1024개로 제한한다. 이 한도를 넘으면 임의로 일부를 고르지 않고 거절한다.
분기·가까운 경쟁 끝점·긴 원본 획 교차·추론 곡선끼리의 교차도 검사한다.

`G`는 **공백 직전 마지막 실선과 반대편 첫 실선**을 지정한다. 기존 Hermite가
가능하면 그대로 사용한다. 큰 U자처럼 그 방식이 거절되면 각 끝점 가까이의 실제
중심선을 따라 부호 있는 방향을 읽고 Bézier 곡선을 제안한다. 기존 진입 방향은
문맥과의 일치 확인에만 쓰며 없는 실선을 대신하지 않는다. 가까운 다른 끝점을
건너뛰는 요청은 거절하며 클릭한 끝점을 자동으로 옮기지 않는다.

큰 곡선이 옆 선에 닿으면 접선 방향을 유지한 채 핸들 비율 2/3, 0.5, 0.4, 0.3을
순서대로 검사한다. 총 길이·처짐·자기 교차를 제한하며 실제 보조 강도로 혼합한
**표시 좌표도** 주변 획과 검사한다. 작은 곡선 문자 획은 통과할 수 있으나 길게
이어지는 주변 선이나 짧아도 뚜렷한 선형 조각은 거부한다. 작은 획 허용은 크기·
기하 조건일 뿐 문자 분류가 아니므로 짧은 실제 선과의 혼동 가능성은 남는다.

미리보기의 같은 끝점을 클릭해야 채택한다. 취소·늦은 작업 결과·레이어 제거와
저장 좌표·한 번의 Undo 경계를 유지한다. 첫 anchor에서 시작한 짧은 `G` 연결을
고도점 제스처로 오인하던 예외도 수정했다. 보통의 고도점·기존 닫기 제스처는 유지한다.

## 원본만 검토한 사례

Validation 도엽에서 원본 전체와 끝점 확대를 보고 동결했다. Calibration·Holdout은
열지 않았다. 사람이 승인한 정답은 없으며 독립 성능 검증·한국 지도 일반화 근거로
사용하지 않는다. 실제 글자 사례는 덧인쇄와 지워진 선을 구별하기 어려워 정답을
만들지 않았다. 숫자 3건과 다른 등고선 끝점을 지정한 음성 1건만 활성 비교에 쓴다.

초기 `kr-10-crop-12-label-500-diagonal`의 오른쪽 끝은 격자선이었다. 원본 전체를
다시 본 검토에서 발견해 철회했고, 원래 v1 바이트를 보존했다. 해당 행·점수는
인용하거나 튜닝하지 않는다. 활성 [v2](data/korea-label-gap-visual-cases-v2.json)는
나머지 3개 양성·1개 음성이며 [철회 기록](data/korea-label-gap-case-audit-v1.json)을
비교 도구가 기본 적용한다. 기존 등고선 v3의 좌표·해시는 그대로다.

양성의 보이는 두 실선만 따로 참조로 기록했고 숨은 구간은 평가에서 제외한다.
음성의 클릭 쌍을 같은 등고선 정확도 점수로 계산하지 않는다. 자동 경로의 가시선
점수는 `visible_f1_2px`로 구분하며, 숨은 곡선을 임의 정답으로 이어 점수를 올리지 않는다.

## 재현과 외부 증거

일반 비교는 기존 스크립트에 `--compare-label-gaps --grid-in-both --before-avoidance 0`을
추가한다. 기존 v3 또는 새 라벨 v2를 `--fixtures`로 지정하고 같은 개발 ZIP·데이터·
USGS/한국 모델·QGIS 의존성을 전달한다. 자동 라벨 비교는 보이는 실선만 점수화한다.
수동 비교는 QGIS Python에서 아래처럼 실행한다. `PYTHONPATH`는 검사할 ZIP을 푼
폴더, `QGIS_CUSTOM_CONFIG_PATH`는 새 임시 폴더를 사용하고 실행 후 제거한다.

```bash
QGIS_PYTHON scripts/qgis_confirmed_gap_review.py \
  --fixtures learning/data/korea-label-gap-visual-cases-v2.json \
  --dataset /path/to/korea/dataset --output /path/to/manual-final.json

python scripts/qgis_confirmed_gap_review.py \
  --fixtures learning/data/korea-label-gap-visual-cases-v2.json \
  --dataset /path/to/korea/dataset --render-json /path/to/manual-final.json \
  --output /path/to/manual-final-images
```

개인 경로·원본·모델·전체 출력·이미지는 git 밖 같은 작업 폴더의
`work/label-gap/` 아래 보존한다. `manual-final.json`은 실제 `G` 저장 결과,
`manual-final-images/`는 원본/기존 거부 뒤 Ink/새 곡선 비교다. 자동 전체 경로는
`final-existing/`, `final-labels/`, 패키지 시험은
`package-qgis-final-9gwjbufy/result.json`, 사용자 흐름은 `clean-profile-final.json`,
성능은 `performance-strict-auto-v3.json`에 있다.
