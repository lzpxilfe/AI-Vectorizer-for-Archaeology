# 0.1.7 사용자 흐름·코드 재검토

2026-11-12 · 미공개 experimental 후보의 후속 검토

외부 사용 사례에서 제기된 지도 입력과 표고점 문제, 사용자가 재현한 연장 중 Undo를
출발점으로 지도 읽기 → 추적 → 이어 그리기 → 고도 입력 → DEM → 저장 흐름을
검토했다. 이번 수정은 편집 의도와 입력값 보존을 위한 것이며 학습 정확도 개선을
주장하지 않는다. 기존 Korea 모델·학습 보조 기본 OFF를 유지한다.

## 재현한 문제와 수정

| 작업 | 확인한 문제 | 수정 |
| --- | --- | --- |
| Shift/Ctrl 수동 클릭 | 깊은 U자 곡선에서 직선 미리보기 후 클릭하면 259개 점의 곡선이 채택됨 | 클릭도 같은 수동 모드를 사용하고 늦은 보조 결과를 무효화 |
| 기존 등고선 연장 | 125m 선을 연장하고 기본 고도창을 그대로 확인하면 0m로 바뀜 | 연장 대상의 유한한 고도를 초기값으로 사용; 명시적 변경 허용 |
| DEM 사용자 스키마 | `id,height_m` 입력에서 `id`의 1·2가 실제 100·120m 대신 자동 선택됨 | `elevation` 외에는 명시적 선택 필요; 같은 레이어의 직접 선택 보존 |
| DEM 불량 좌표 | NaN XY를 포함한 선의 정상 정점 일부가 TIN에 들어가 결과를 조용히 변경 | 등고선·표고점의 XY를 생성 전에 검사하고 해당 입력 전체 거부 |
| 작은 화면 | 1024×700 요청에도 패널 최소 높이 약 1179px, 고급 옵션 시 1484px | 스크롤 컨테이너와 줄바꿈으로 하단 작업에 접근 가능 |
| 준비 상태·설명 | 입력이 비어도 시작 버튼 활성, Enter를 파일 저장으로 오해할 문구 | 지도·출력 선 레이어가 준비되어야 시작; 선 확정과 파일 저장을 한·영으로 구분 |

## 검토 범위

- 추적: 클릭·미리보기 일치, 수동 경로, 비동기 결과, 기존 선 연장, 고도와 편집 Undo,
  도구 종료·레이어 제거·플러그인 해제.
- 데이터: NoData/alpha 래스터, WMS형 provider의 해상도 경계, DEM 필드·좌표·CRS·
  저장 상태·출력 교체, 모델 해시·오프라인 검증·캐시·늦은 콜백.
- UI: 한국어·English, 입력이 없는 첫 실행, 작은 창과 고급 옵션, 고도 필드 변경,
  추적/DEM/주석 작업과 도움말의 일치.
- 배포: 기본 모델/데이터 보존, 버전·문서, 명시적 새 ZIP과 소스 일치, 격리 QGIS
  profile 실행 및 원격 호환성 검사.

## 검증과 산출물

후속 CI에서 Linux QGIS 3.22/3.44의 영어 문구가 360px 폭을 21px 넘는 문제를
확인했다. 긴 문구를 여러 줄로 표시하고 복구·색상 버튼을 세로로 배치했다.
Fusion 18px 글꼴과 HED/MobileSAM/SAM 설치 필요 상태도 확인한다.
QGIS 4의 레이어 선택 직후 준비 상태 실패는 이벤트 처리 전후의 선택값과 상태를
분리 기록해 진단한다. 이 단계의 새 산출물은
`ai_vectorizer-0.1.7-review-v2-2026-11-12.zip`
(`854edccee92134d2ca1683c766c7a220a95bd45ed3c48ae309d681fb1638508c`)이며
최종 호환성 검사는 진행 중이다. 아래 수치는 그 전 재검토 ZIP의 완료 기록이다.

후속 후보는 `ai_vectorizer-0.1.7-review-2026-11-12.zip`이며 SHA-256은
`f368c9c5c631b1cc39d030434c7a73157edaf4c8422e5a6132a8e20fb9665e8e`이다.
metadata는 `0.1.7`, `experimental=True`를 유지한다.

| 검사 | 현재 결과 |
| --- | --- |
| 일반 Python | 1,246 passed, 195 skipped, 171 subtests passed |
| 실제 QGIS 3.44.8 | 15개 모듈, 213 tests, 실패·오류·skip 0 |
| 새 ZIP 격리 설치 | import와 plugin loader 통과, 임시 profile 제거 |
| 작은 화면 | KO/EN × Advanced off/on, 창 1024×700·dock 360px, 가로 스크롤 0; Start/DEM/Help 접근 가능 |
| 결정적 패키지 | build/check 통과 |
| 기존 지도 회귀·원격 CI | 최종 검사 진행 중, 첫 후보의 통과를 새 소스 결과로 대체하지 않음 |

macOS 실제 QGIS를 재시작해 새 스크롤 패널 로딩을 확인했다. 좁은 창 크기와
하단 버튼 접근의 정량 확인은 실제 QGIS Qt 위젯 테스트로 수행했다. desktop
자동화의 좌표 클릭/스크롤이 `noWindowsAvailable`로 제한되어 실제 마우스로
전체 하단을 검토했다고 주장하지 않는다. 사용자 프로젝트는 열거나 수정하지 않았다.

최종 검증 결과는 별도 evidence JSON에도 결속한다. 첫 후보
`a3f4eebf07b51febf3a6f9eeddc2213764c9fda407617611f1811bfbae72ba28`은 덮어쓰지 않으며,
기존 [검증 기록](RELEASE_READINESS_0.1.7.md)의 테스트를 후속 코드의 결과로 재사용하지 않는다.

## 남은 한계

- 사용자가 제보한 실제 WMS 서버·DEM 프로젝트의 완전한 재현은 아니다. 테스트는
  QGIS의 실제 provider/Qt/Processing과 출처가 분리된 재현 fixture를 사용한다.
- Windows GUI·다양한 HiDPI 화면의 직접 사용성 검토는 수행한 범위를 넘겨 주장하지 않는다.
- 사람 검수 Holdout 정확도·사용자 작업 시간·새 모델의 일반 글자 성능 개선을 입증하지 않는다.
- 전체 코드를 검토해도 모든 결함의 부재를 증명하지는 않는다. 결과는 위 흐름과
  명시한 테스트에 한정한다. 공식 업로드·tag·Release는 아직 만들지 않았다.
